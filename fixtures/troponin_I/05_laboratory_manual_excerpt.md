# Laboratory Manual (Excerpt) — Specimen Handling

- **Study:** BM-2026-01
- **Document:** Central Laboratory Manual, v1.2
- **Applies to:** Troponin I (Troponin I Ultra) samples

## 1. Specimen type

- **Matrix:** serum (SERUM)
- **Collection tube:** serum separator tube (SST), gel barrier
- Minimum volume: 2.0 mL whole blood

## 2. Collection and processing

1. Venous blood drawn by standard venipuncture into an SST.
2. Allow to clot at room temperature for 30 minutes.
3. Centrifuge at ~1500 × g for 10 minutes.
4. Separate serum into a labelled aliquot tube.
5. Analyse within 24 hours when stored at 2–8 °C; if analysis is delayed beyond 24 hours,
   store at ≤ −70 °C and analyse within 30 days. Avoid freeze–thaw cycles.

## 3. Labelling

Each aliquot is labelled with a specimen identifier of the form
`S-<4-digit subject>-T<timepoint>` (e.g. `S-0001-T1`).

## 4. Sampling schedule

- **Anchor:** hospital admission
- **Serial sampling required:** yes
- **Timepoints:** admission (0 h), 3 h, 6 h

Rationale: the rise or fall across serial samples is part of the finding; a single admission
value cannot distinguish acute release from chronic elevation.

## 5. Reagents, calibration and quality control

- Reagent packs assigned a **reagent lot**; calibrators assigned a **calibrator lot** — recorded
  per analytical run.
- A calibration is performed and accepted before results are released.
- Quality control (≥ 2 levels) must be accepted for the shift covering the run; results are not
  released until QC passes.

## 6. Analysis

- **Instrument:** ADVIA Centaur XP (see `03_assay_instructions_for_use.md`).
- **Method:** immunoassay.
- Results are checked against the control record, the censoring state is derived against the
  assay limits, and the run is released.

## 7. Recording per run (for the run record)

For each analytical run the laboratory records:

- run identifier, laboratory identity and accreditation
- instrument serial number and software version
- reagent lot and calibrator lot
- calibration date/time and acceptance
- QC acceptance record
- for each specimen: collection time, analysis time, censoring state, repeat status
- any deviation from this manual
